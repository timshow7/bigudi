# Бигуди — навигатор по взрослой жизни

Учебный веб-проект, представляющий собой гайд и сообщество для подростков и студентов. Сервис помогает разобраться в бытовых вопросах, рецептах и базовой медицине, а также адаптироваться к самостоятельной жизни. 

## Особенности интерфейса

Главная особенность проекта — интерактивный план квартиры. Пользователь "находится" в квартире, где каждая комната выступает в роли категории:
- Кухня — рецепты и хранение продуктов
- Ванная — стирка и уборка
- Спальня — сон и здоровье
- Гостиная — быт и техника
- Коридор — документы и финансы

Внутри комнат расположены предметы (подкатегории). Кликая на них, пользователь переходит к статьям или обсуждениям на форуме. Также предусмотрен альтернативный список категорий для удобства на мобильных устройствах.

Важное примечание: на текущем этапе интерактивная карта квартиры является концептуальным прототипом. Дизайн и механика взаимодействия с ней (графика, анимации, расположение элементов) будут полностью перерабатываться и дорабатываться в финальной версии продукта.

## Стек технологий

- React 18 — библиотека для построения интерфейса
- TypeScript — типизированный JavaScript
- Vite — сборщик проекта
- Tailwind CSS 3 — стилизация
- React Router DOM — навигация между страницами (используется HashRouter для корректной работы на статических хостингах)
- Lucide React — иконки

## Реализованный функционал

- Главная страница со схемой квартиры
- Просмотр статей и обсуждений (с табами и фильтрами)
- Лента форума с сортировкой и фильтрацией по комнатам
- Создание новых тем на форуме (с валидацией полей)
- Профиль пользователя (избранное, мои темы, настройки)
- Поиск по статьям и обсуждениям с подсветкой совпадений
- Сохранение состояния (избранное, созданные темы) в localStorage браузера
- Адаптивная верстка (под мобильные, планшеты и десктоп)

## Как запустить проект локально

Для запуска потребуется установленный Node.js.

1. Клонируйте репозиторий или скачайте архив.
2. Установите зависимости:
   npm install
3. Запустите локальный сервер разработки:
   npm run dev
4. Откройте в браузере http://localhost:5173

## Структура проекта

- src/components/ — переиспользуемые UI-компоненты (карточки, кнопки, фильтры)
- src/pages/ — страницы приложения (Главная, Профиль, Поиск, Форум и т.д.)
- src/data/ — статические данные (статьи, комнаты, темы форума)
- src/store/ — глобальное состояние (Context API)
- src/types.ts — типы данных TypeScript

## Примечание

На текущем этапе реализован рабочий прототип клиентской части (frontend-only). Данные хранятся локально в браузере. В дальнейшем планируется разработка backend-части, добавление авторизации и модерации.
